Visual Identity · v1

A tracking command center — not a generic SaaS panel.

EasyTrac borrows Stape's information architecture and UX patterns — and nothing of its look. This is our own identity: dark, confident, Arabic‑first, technical but approachable. High contrast, generous space, a disciplined blue, and glass only where it sharpens hierarchy.

ground #0A0A0A signal #2F6BFF Arabic‑first · RTL native radius 12–16px soft shadows · subtle glow

Personality in one line

Modern · Premium · Clean · Enterprise · Confident · Minimal. Every screen should feel engineered — like instrumentation for a store's tracking, not a dashboard template. The EasyTrac mark, wordmark, and voice stay; the visual language below makes the product unmistakably ours and visibly a tier above Stape.

01 · Foundations

Color

A near‑black ground with one decisive blue. Zinc neutrals for text and surfaces; semantic colors reserved strictly for state — never decoration. The accent hue and the semantic hues are kept separate so "needs attention" always reads instantly.

Rule

Blue is for what you can act on. Green/amber/red are for system state only. If a color isn't communicating an action or a state, it shouldn't be colored — the ground stays black and the type stays zinc.

03 · Foundations

Space, radius & light

Generous spacing is the biggest lever for "premium." An 8px rhythm, radii of 12–16px, soft low‑opacity shadows, and a single restrained blue glow reserved for the primary object on a screen. Glass (backdrop‑blur) appears only to lift the one panel that matters — never as wallpaper.

Spacing

8px rhythm

Component padding 16–24px; section gaps 60–80px. Let it breathe.

Radius

12–16px

Rounded, not pill (except tags/status). Consistent across every surface.

Elevation + glass

Soft & subtle

Large, faint shadows. Glass only to lift the hero panel — like this card.

04 · Components

Buttons & actions

One primary action per screen — a single gradient‑blue button with an inner highlight and a soft blue cast. Everything else is a quiet ghost. Hover lifts subtly; press settles. Motion is 120–200ms, eased, and honors reduced‑motion.

08 · Principle

Every page answers three questions

What is happening?

A status headline + live signals are the first paint. State before detail, always.

What should I do next?

Exactly one primary (blue) action per screen, driven by current state.

Anything need attention?

A single amber/red banner rises to the top when — and only when — something is wrong.

10 · Motion

Motion language

The product should feel alive — continuously monitoring — while staying calm and premium. The rule that makes both true: ambient motion is slow and quiet; interactive motion is fast and precise; only one thing moves at a time. Everything honors prefers‑reduced‑motion.

Timing scale

Instant80ms
Quick140ms
Standard200ms
Deliberate320ms
Ambient (loop)1.4–2s

Instant = hover tints, press. Quick = buttons, toggles, pill state. Standard = panel & content cross‑fades, toasts. Deliberate = section/modal entrance, the health ring filling. Ambient = live pulse, skeleton shimmer, breathing glow — always ≥1.4s so it reads as calm monitoring, never busywork.

A single breathing dot (2s ease‑in‑out) says "watching." Low amplitude, never blinking. One per context.

Live Event Stream

New signals arrive with a 320ms Entrance ease + a brief blue highlight that fades over ~1.2s. Unhurried — calm real‑time.

Behavior specs

Status transitions

On a state change, the pill cross‑fades color over 200ms and its dot pulses once for attention, then settles. Errors never loop — calm, not alarming. The health ring animates its fill over 320ms; numbers count up on first load (tabular).

Loading transitions

Skeletons shimmer on a 1.4s linear loop and hold the final layout (zero shift). When data lands, the skeleton cross‑fades out and content rises in with Entrance ease; lists stagger 40–60ms per row.

Success feedback

Toast slides up + fades in (Standard, Entrance ease); the check‑mark draws its stroke (300ms). Auto‑dismiss after ~4s with a thin progress hairline; exits down + fades (Quick).

Error feedback

Same calm entrance — then a single ≤6px horizontal nudge (one cycle, never a violent shake). Persists until addressed, and names the fix. Red is used once, at the top.

The feeling

Alive but calm: ambient loops are slow and faint; interactions are crisp and immediate; one primary motion at a time. Under reduced‑motion, all ambient/looping stops — state still changes instantly, just without the theater.

11 · Guardrail

Not Stape — the boundary

We studied Stape's structure and copied none of its skin. This line is explicit so no future screen drifts into imitation.

✓ Study from Stape

  • Information architecture & object model
  • Navigation & dashboard hierarchy
  • Onboarding & user flows
  • Progressive disclosure & UX patterns

✕ Never copy from Stape

  • Colors, icons, cards, layout styling
  • Typography & branding
  • Visual identity of any kind
  • Anything that makes us look like a clone
North star

A user should recognize EasyTrac instantly as its own product — Arabic‑first, darker, more confident, more premium than Stape. Same problem space; a stronger visual identity.
